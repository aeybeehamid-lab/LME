LME CTO Plan

LME Build Roadmap

Version 1.0 · Date: 2026-06-02 · Target: 12 weeks (range 10-15 weeks)

Phase 0 (Week 1): Foundations and Controls

  • Finalize product decisions log and architecture.
  • Set up repos, environments, CI, coding standards, and secrets management.
  • Provision Firebase, Paystack, PostgreSQL, and file storage.
  • Deliverable: architecture approval, schema lock, project skeletons.

Phase 1 (Weeks 2-4): Core Backend and Integrations

  • Implement auth/roles, orders, payments, riders, and waybills modules.
  • Implement Paystack webhooks with signature verification and idempotency.
  • Implement 10-minute escalation and 30-minute unresolved refund logic.
  • Deliverable: backend API v1 with tested order/payment state machine.

Phase 2 (Weeks 5-6): Rider App (Android-first)

  • Build job board, first-to-accept lock, active job flow.
  • Build status progression and mandatory proof-of-delivery upload.
  • Build earnings views and delivery history.
  • Deliverable: internal rider pilot app.

Phase 3 (Weeks 7-9): Customer App

  • Build onboarding, profile, saved addresses, category booking flows.
  • Build checkout with transparent pricing and urgent surcharge display.
  • Build tracking timeline, history, and complaint submission flow.
  • Deliverable: end-to-end customer booking and delivery lifecycle.

Phase 4 (Weeks 10-11): Executive Dashboard

  • Build order feed, escalations, assignment, cancellation, refunds.
  • Build complaints workflow and rider management.
  • Build finance core: money in, commissions, refunds, net.
  • Deliverable: launch operations command center.

Phase 5 (Week 12): Hardening and Launch

  • Complete QA, regression, reliability tests, and incident runbooks.
  • Finalize monitoring dashboards and alert routing.
  • Execute staged rollout and go-live checklist.
  • Deliverable: production launch candidate.

GitHub Workflow

  • Feature branches and PRs per milestone.
  • At least one push per day during active development.
  • Conventional commits and required checks before merge.
